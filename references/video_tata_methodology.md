# AI视频/漫剧方法论（Agnes 体系执行版）

> 本文件沉淀一套从剧本到成片的完整 AI 视频生产方法论，已在 Agnes 体系上实测跑通。
> 与 `prompt_methodology.md`（5维度/情绪三法/过程写法6招）**互补不冲突**：那份讲"怎么写一句话"，这份讲"一部片子怎么从头做到尾 + 人怎么活过来"。
>
> **★ 融合进生产流程的执行版见本仓库 `references/prompt_templates.md`**
> （9 步 SOP + 冲突裁决 + 统一九段骨架 + 准入准出）。**做片子时以那份为准**，本文件是它的叙事层素材库。

---

## 0. 一句话总纲

**AI 视频"假"，不是模型不行，是输入不对。**
按固定流程走 + 情绪前置 + 写纯动作 + 锁人锁景 = 可控的 AI 大片。

---

## 1. 六步工作流（生产顺序不可乱）

```
① 剧本/分镜   用 LLM 写故事+分镜脚本（可上传小说一键出剧本）
② 锁角色      建"定妆正脸图"，锁定人物特征，全片复用同一张
③ 锁场景      生成场景锚点图，统一光影色调，全片复用同一张
④ 写提示词    按 §4 模板填（情绪最优先）
⑤ 生成镜头    逐镜头生成，每镜都同时喂 角色图 + 场景图
⑥ 后期        剪映：拼接 / 转场 / 音频 / 调色 / 字幕
```

**规则**：②③ 没做完，**不许**开始 ⑤。角色图和场景图是后面所有镜头的地基，临时补做 = 全片风格漂移，前面所有镜头作废。

| 步骤 | 通用方案 | Agnes 落地 |
|---|---|---|
| 锁角色 | 全能参考模式建角色参考 | 定妆正脸图作为 `<Picture 1>` |
| 锁场景 | 场景锚点图 | 场景图作为 `<Picture 2>` |
| 生成 | 参考图 + 提示词 | `agnes-video-2.5`，`tool_agnes.py --extra-images` 多参考 |
| 配音 | 视频编辑软件 TTS | 剪映 TTS（Agnes 视频不带音轨，配音必须单独做） |

## 2. 五维度框架（每条 prompt 的底层结构）

| 维度 | 写什么 |
|---|---|
| 基础定调参数 | 风格、画质、比例、时长 |
| 分镜时序与运镜 | 动作顺序、镜头运动（推/拉/摇/移） |
| 光影色调 | 光的方向、软硬、色温、整体色调 |
| 音频设计 | 对白、音效、配乐（**Agnes 侧仅作画面节奏参考，音轨另做**） |
| 服化道设定 | 服装、化妆、道具，保证全片统一 |

---

## 3. 两条"模型怎么读 prompt"的硬规则

1. **词序越靠前，权重越高。** 最重要的信息写最前面——所以情绪必须排在所有画面参数之前。
2. **出问题只改那一句，不要整段重写。** 整段重写 = 前面调好的参数全部洗牌，越改越崩。定位到是"动作穿帮"还是"光影不对"，只动对应那一行。

---

## 4. ★ 提示词污染（最高频的穿帮来源）

**机理**：模型会根据关键词**联想**出该词的刻板印象包，附赠一堆你没要的东西。
典型：写"医生" → 附赠白大褂/听诊器/医院走廊；写"末日废墟" → 附赠绿植藤蔓/黄昏暖光/干净的建筑切面。

**解法：删掉联想词，改成纯粹的物理动作描述。做减法反而更好。**

| ❌ 会污染 | ✅ 改成纯物理描述 |
|---|---|
| 他很愤怒 | 他下颌收紧，拳头攥起，指节发白，胸口起伏两次 |
| 医生在救人 | 穿深色外套的男人蹲下，双手压住对方胸口，节奏均匀 |
| 悲伤地哭 | 视线先下垂，喉结动了一下，眼眶泛红但没落泪 |
| 末日废土 | 灰白色水泥碎块堆到膝盖高，天空是均匀的灰，无绿植 |

**通用铁律**：凡是"情绪/身份/职业/风格标签"类抽象词，一律翻译成**可被摄像机拍到的动作或物件**。

## 5. ★ 让人物有"真人感"（本方法论的核心）

### 情绪三件套
1. **情绪前置**——情绪是总基调，优先级最高，所有画面参数（光、色温、运镜速度）围绕情绪匹配，而不是各自为政。
2. **分层写法**——基调 → 动作 → 镜头 → 光影 → 收尾，标准化分层，强制产出连续情绪质感。
3. **三段式递进**——情绪要有变化过程，不是静态一张脸。

### 让人物活过来三步
1. **限制情绪幅度**：别写"很开心"，写情绪**强度档位**（弱/中/强），走微表情实力派。
2. **给情绪配动作**：带**上半身**动作（肩、手、头、胸口），构建完整姿态，摆脱证件照式摆拍。
3. **给情绪加时间顺序**：描述情绪的**变化过程**（从A到B），拒绝静态脸。

### 真人行为公式（单人）—— 直接套
> **人物身份 + 具体小事 + 下意识小动作 + 情绪落点**

示例："穿工装外套的男人（身份）蹲在碎砖堆旁翻找（具体小事），手指反复摩挲一块金属片边缘、指腹蹭掉灰（下意识小动作），视线突然停住，呼吸变浅（情绪落点）。"

### 多人场景
- **一人主动行动、一人被动反应**，避免全员摆拍、全员盯镜头。
- **铁律：行为动机 > 五官细节。** 花力气写"他为什么做这个动作"，而不是"他眼睛多大、鼻子多挺"。

---

## 6. 一致性控制（解决人物/场景崩盘）

1. **锁人物**：同一张定妆正脸图全程复用；换服装时只改服装描述，不改脸的描述。
2. **锁场景**：同一张场景锚点图全程复用；光影色调写在场景句里，全片共用。
3. **无缝拼接**：按时长规则拆镜头，写分镜脚本，用"尾帧接力 + 批量生成"实现衔接；
   尾帧接力**最多 3 镜**，超过必须回退到角色图重新起镜（误差会累加）。

## 7. 镜头语言

### 15 种电影级镜头设置（按五大类分）
人物出场 / 对话 / 情绪 / 动作 / 环境 —— 每类约 3 种。
用法：**一个分镜只服务一个目的**，先定这一镜属于哪一类，再选对应镜头设置，不要一镜里同时又要出场又要交代环境。

### 5 个高级运镜
| 运镜 | 实现要点 |
|---|---|
| 贝氏英雄环绕 | 主体保持静止，镜头绕行 90–180°，背景持续变化 |
| 子弹时间 | 主体极慢动作 + 镜头常速环绕，写"时间近乎凝固" |
| 万物 FPV 跟随 | 第一人称视角贴着物体飞行/穿过，写"镜头从 XX 内部穿过" |
| 百万级机械臂运镜 | 起点→终点写死，中间路径连续无剪辑（一镜到底感） |
| 希区柯克变焦 | 主体大小不变、背景压缩/扩张，写"推镜头同时拉焦" |

> 通用方案：首尾帧或全能参考 + 提示词实现。Agnes：写进 prompt 的运镜句，`seconds` 给足（复杂运镜 ≥8s）。

## 8. 可直接填写的模板（10 段，词序别乱）

```
【基础定调】[风格]，[画质]，[比例]，[时长X秒]
【情绪（最优先，写最前）】[情绪词]，情绪强度[弱/中/强]，情绪变化：从A到B
【主体/人物】[身份]，[外形特征]，[服装]
【动作（纯物理动作，别写联想词）】[具体小动作]，[上半身动作]，动作顺序：1… 2… 3…
【环境】地点[在哪]，时间[白天/黄昏/夜晚]，氛围[什么情绪氛围]
【镜头】[景别]，[角度]，[运镜]
【光影色调】[光的方向]，[软硬]，[色温K值]，[整体色调]
【服化道】[服装/道具]，保持与角色参考一致
【音频】[对白/音效/配乐]
【限制】不要[塑料感/多余元素/穿帮]
```

### 单人填空示例
```
电影感，高清，16:9，3秒；
悲伤，情绪强度中，从强忍到落泪；
古代女子，20岁，素色衣衫；
低头，手微微颤抖，肩膀先沉再抬眼；
破庙，雨夜，压抑清冷；
中景，平视，缓慢推近；
侧前方冷光，柔光，色温4500K，青灰色调；
素衣不变；
雨声，低沉弦乐；
不要僵硬摆拍，不要五官夸张。
```

## 9. 与 Agnes 体系的差异对照

| 通用方案 | Agnes 落地要点 |
|---|---|
| 词序越靠前权重越高 | 同样适用。情绪段必须排第一 |
| 全能参考模式 | 无该模式 → 用 `--extra-images` 多图参考，角色图 + 场景图同时喂 |
| 音频设计写进 prompt | Agnes 视频**不带音轨**，音频段只用于指导画面节奏，配音走剪映 TTS |
| 时长自由 | `size` 必须字符串 `"720P"`，`seconds` 字符串 `"4"`–`"12"` |
| 失败重跑 | 免费 Flash 队列可能返回 **503 `video_queue_full`**，需退避重试 |
| 批量生成 | 并发 ≤3，超过容易队列满 |

## 11. 生成前自检清单（每镜过一遍）

1. 情绪段是否排在最前？是否写了**强度档位**和**变化过程**？
2. 动作是否为**纯物理描述**（能拍到），有无残留联想词？
3. 有没有**上半身动作**？有没有**时间顺序**（1→2→3）？
4. 角色图 + 场景图是否**本镜也喂了**？
5. 背景是否写死"干净无人/仅一人"？
6. 负面清单是否在**尾部**逐项直列？
7. 上一镜到本镜是否**只改了一个维度**？（出问题才改，别顺手全调）
