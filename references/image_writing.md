## ★ 标准做图工作流（2026-09-19 定稿 —— 出图一律按此走）
> 本技能 = 出图/出片的**唯一标准入口**。用户提"出图 / 做图 / 生成图片 / 海报 / 封面 / 装修图 / 产品图 /
> 人物图 / 整套"时，默认走下面这条流水线，不再零散即兴。

**六步通用流水线**
1. **判类型** → 按下方「场景路由表」选对应 SOP（这是每次出图的第一动作）
2. **搭结构** → 按九要素填 prompt：用途 + 主体 + 场景 + 风格 + 构图 + 光线 + 细节 + 文字 + 禁止项
3. **上质感** → 按场景叠加其一：写实层（去 AI 感）/ 人物六词组 / 米其林光（三者方向不同，别同用）
4. **定尺寸** → 竖版封面 `1024x1536` · 横版纪实/多人 `1536x1024` · 方版 `1024x1024`
5. **生成** → `image`；多张/整套走并发（`ThreadPoolExecutor(max_workers=3)`）
6. **交付** → 单图/多图用 `present_files`；整套复制到独立目录 + 写 `index.html` 画廊（近景组/远景组）；
   **海报类一律"AI 底图无字 + PIL 叠字"**

**场景路由表（对号入座）**
| 需求 | 走哪套 | 关键动作 |
|---|---|---|
| 产品 / 美食图 | 美食三步法（拆白底图 + 场景图 + 融合） | 光线三要素写死：方向 / 软硬 / 色温 K |
| 已有美食图提质 | 米其林光（六抓手叠加） | `edit` 叠光影；主体保护写死负面词 |
| 人物图 / 种草图 | 九要素 + 写实层六词组 + 防大头贴三件套 | 必写镜头焦距 / 构图 / 景别 |
| 空间 / 装修 / 家居图 | 装修 SOP | 先锚风格；近景配远景、远景 ≥ 1/3；禁"3D 效果图" |
| 促销 / 宣传海报 | 海报五步 SOP + 已沉淀布局模板 | 底图无字、PIL 叠字；**促销主视觉反而要 3D** |
| 整套 / 批量 | 整套批量模板 | 共用风格段锁死，只换主体 / 构图 |
| 改图 / 图生图 | `edit` 局部修改 | 一轮只改一个维度；503 走兜底 |

**七条铁律（每次出图都要过一遍）**
1. **中文不进图**：图内中文必乱码 → 一律"AI 底图无字 + PIL 后期叠字"。
2. **负面词拼尾部**：接口无 negative 字段，负面清单 append 到 prompt 末尾，逐项直列（不用"X 以外"这种歧义句式）。
3. **抽象词必须翻译**：不说"高级感"，说"大面积留白 + 单一强调色 + 元素不超过三种"。
4. **数量 / 动作要写死**：唯一物体放主体句开头（"画面中只有一只…"）；"正在进行时"动作写"紧贴/接触"。
5. **写实层 ≠ 商业提质**：种草图用写实层（去 AI 感），产品/海报用商业精致（米其林光），方向相反别混。
6. **远景 ≥ 1/3**：整套素材必须有景别梯度（近景看材质、远景看格局）。
7. **edit 503 是常态**：edits 队列不稳，重试一次仍挂 → 兜底为"原描述 + 修改意见合入 t2i 重生成"（牺牲构图一致性）。
8. **兜底要能脱离 chat**：`chat`（含图像理解）2026-09-20 起也会 `HTTP 429` 免费额度限流 →
   兜底链不能依赖"用图像理解转描述"，改为**阿鹅自己读图 + 手写产品/画面描述 + t2i 重生成**最稳。

## 装修/家居空间图出图 SOP（2026-09-19 整合：原"空间/家居类"升级）
装修图 = 空间类，最大翻车点是**透视崩**（墙线歪、鱼眼畸变、地平线斜）和**渲染感**（CG/3D 效果图味）。
核心纪律：**近景看材质、远景看格局**，整套必须有景别梯度（见下方「景别梯度」节，远景不少于 1/3）。

**① 先锚定风格（决定配色 + 光线 + 材质词）**
| 风格 | 配色 | 光线 | 关键材质词 |
|---|---|---|---|
| 奶油风（已验证） | 米白/奶咖/浅棕低饱和 | 柔光、纱帘漫射光 | 羊毛绒、针织、羊羔绒、圆润弧线、被云朵包围 |
| 原木风 | 橡木原色 + 白 + 少量黑 | 自然窗光、暖阳斜入 | 实木纹理、藤编、亚麻、绿植 |
| 法式/轻法式 | 奶油白 + 线条雕花 + 复古金 | 暖黄壁灯、晨光 | 石膏线、人字拼地板、丝绒、黄铜 |
| 现代极简 | 黑白灰 + 单一强调色 | 无主灯、中性光 | 岩板、哑光金属、隐形门 |
| 侘寂风 | 微水泥灰 + 陶土 + 原木 | 单一柔和侧光、阴影明显 | 手工肌理、未上釉陶器、留白 |
> 拿不准风格时，先用 `chat` 要 3 个视觉方案再生成（见七要素流程）。

**② 共用风格段（每套锁死，整批复用）**
```
[风格] 原木风日式客厅，低饱和自然色，橡木原色地板与家具，白墙，少量黑色细线条点缀
[光线] 午后自然窗光斜入，柔和漫射，明暗自然过渡，无 harsh 阴影
[画质] 真实室内摄影，自然画质，非效果图，轻微生活痕迹，日常拍摄
```
> 治愈/温馨感靠"轻生活痕迹"：抱枕压痕、随意搭着的搭毯、马克杯热气、绿植——别写满屋精致无瑕。

**③ 近景段（看材质/情绪）**
```
近景特写，画面被一组家具/材质占据大部分，背景自然虚化：
例如沙发一角（能看到针织纹理与抱枕压痕）、木质餐桌（木纹与杯垫）、窗边阅读角
```
**④ 远景段（看格局，给设计师看的是这层，复用）**
```
采用广角镜头拍摄的远景全景视图，能看到连续两个以上的空间层次，
透视正确、墙角线笔直、地面水平，空间纵深明显，
前景有家具一角，中景是主体空间，远景能看到更远处的房间或窗外景色，层次分明。
```

**⑤ 装修图专属禁忌（必加，比通用更狠）**
`不要CG渲染、不要3D效果图、不要鱼眼畸变、不要透视扭曲变形、不要倾斜的地平线、不要空无一人的样板间塑料感、不要改变建筑结构`。
> "不要3D效果图"是家装 AI 图第一大坑（默认就是渲染图味）；"不要改变建筑结构"防模型把承重墙/门洞乱挪。

**⑥ 出图流程**
1. 锚定风格 → 写共用风格段（锁死）；
2. 按"房间 + 景别"列清单（客厅近景/客厅远景/卧室远景/厨房/玄关/卫浴/飘窗…），远景 ≥ 1/3；
3. 共用段 + 各张"主体/构图"拼接，并发生成（max_workers=3，见「整套/批量出图」节）；
4. 复制到独立目录 + 写 `index.html` 画廊，按"近景组 / 远景组"分组展示。

常用远景镜头：客餐厅一体广角 / 玄关望向客厅（走廊透视）/ 落地窗全景（室内外景深）/
主卧套房（含衣帽间门）/ 横厅 LDK 一体（超广角）/ 阳台望向室内（由外向内）。
尺寸：横版 **1536x1024**（空间纪实首选）；竖版 **1024x1536**（封面/单图种草）。

## 整套/批量同风格出图（2026-09-19 奶油风 16 张验证）
用户说"出一整套"时，不要一张张写 prompt，按这个模板：

1. **共用风格段**（氛围 + 配色 + 光线 + 画质）锁死，整批共用，保证调性统一。
2. **每张只换**：主体 / 场景 / 构图。
3. **禁止项段**也共用。
4. 用 `subprocess` + `ThreadPoolExecutor(max_workers=3)` 并发调用，失败退避重试一次。
   实测：7 张一批约 2 分钟，零失败。
5. 交付时把成品复制到一个独立目录 + 写一份 `index.html` 画廊（一屏浏览整套），比散落的卡片好用。

### ★ 景别梯度（硬性要求，2026-09-19 用户反馈："除了近景还需要有远景"）
**整套素材必须像拍片子一样有景别配比**，不能全是同一距离：
| 景别 | 作用 | prompt 写法 |
|---|---|---|
| 远景/大全景 | 交代**空间关系**、户型格局 | `远景镜头：广角拍摄，完整展现整个空间，天花板和地面都可见，透视纵深强烈` |
| 中景 | 单个功能区（如整面沙发墙、整张餐桌） | `中景构图，某区域占画面三分之二` |
| 近景/特写 | **情绪与材质**（治愈感基本靠这一层） | `近景特写，某某占画面大部分，背景虚化` |

- 一套 9-16 张的配比建议：**远景不少于三分之一**。
- 远景常见坑：透视扭曲 → 禁止项加 `不要鱼眼畸变、不要透视扭曲变形、不要倾斜的地平线`。
- 交付时在画廊页按"近景组 / 远景组"分组展示，用户挑图更快。

## 美食/产品图「拆分生成 + 三步融合」（2026-09-19 新增，烘焙产品优先用）
核心思路：**别让 AI 一次画出"食物 + 场景 + 光"**——一次全生成必然翻车。
拆开做再合，出图可控、高级、不翻车。

**第一步：先做美食白底图**（单独把食物本身拍准、拍有食欲）
- 白底或浅灰底，只描述食物：形态、切面、材质、光泽、蒸汽、糖粉等细节词。
- 这一张是"产品资产"，要单独定稿，不合格就重出。

**第二步：再做场景图**（单独搭氛围场景与光影，**不放产品**）
- 只描述环境：台面材质、背景道具、色调、光的方向与色温。
- 场景调性必须与产品搭（黑金品牌就不要奶油木桌乱入）。

**第三步：三步口诀融合**（上传白底图 + 场景/打光提示词）
1. **精准造景**：先想清"场景和产品搭不搭"，再写场景提示词，贴产品调性。
2. **科学打光**：光线三要素写死——**方向 / 软硬 / 色温 K 值**，直接决定食欲和质感。
   本机可用写法：
   | 要素 | 可选值 |
   |---|---|
   | 方向 | 侧逆光（勾轮廓）· 右上方 45° 主光 · 左前方窗光 · 顶部柔光 |
   | 软硬 | 柔光箱（软，适合奶油蛋糕）· 硬光小角度（硬，适合酥皮/焦糖质感） |
   | 色温 | 3200K 暖黄（温馨/面包）· 4000-4500K 中性（最接近真实食材）· 5600K 日光（清爽/冰品） |
3. **场景迁移 / 一键合成**：把白底产品放进场景，**务必强调"光影方向一致、产品与环境投影统一、色温统一"**。
   - 本机实现：`edit` 传白底图 + "把产品自然放入场景，光影与原场景一致"。
   - `edit` 队列 503 时兜底：用图像理解模型把白底图的细节（形态/切面/颜色）转成一段**极细描述**，
     再连同场景段一起 t2i 重生成——代价是产品形态一致性下降，适合非精确外观的产品（面包、饮品）。

> 品牌落地：烘焙新品（冰面包/蛋糕/欧包）做"产品主视觉"时走这套；
> 生活流种草图不必拆，直接用九要素 + 写实层一次生成即可（那是要"随手拍"的质感）。

## 「米其林光」：已有美食图一键升级（2026-09-19 卡片整合，AI修图合集第2集）
核心思路：**不是"改食物"，是只加光线、色调、质感，不动原图内容**——
保留原图主体与构图不变，只叠加一层「光+色+质感」提示词，把"餐桌小食"升级成"米其林大餐"。
与三步法是姊妹篇：**三步法管"从零造"，米其林光管"已有图提质"**。实现走 `edit`（图生图）。

### 六抓手叠加模板（可直接抄）
```
保留原图主体与构图不变，只升级光影与质感：
[光效] 侧前方柔和主光 + 伦勃朗光（明暗对比强），主体高光突出、质感饱满
[景深] 背景压暗虚化、浅景深，前景暖调散景光斑；高光不刺眼、暗部细节丰富
[色调] 暗调暖棕、焦糖暖金主光，低饱和背景衬托高饱和主体，浓郁但不艳俗
[质感] 油光、肌理、汁水极致还原 + 轻微胶片颗粒
[氛围] 高级、温暖、诱人，米其林餐厅精致感，如同美食电影剧照
```
一句话记忆：**伦勃朗光 + 暖焦糖色 + 浅景深光斑 = 米其林光**。

### 本地适配与边界
- 实现：`edit --images 原图 --prompt "<六抓手模板>"`；edit 队列 503 时兜底 =
  原图细节描述 + 本模板合入 t2i 重生成（牺牲构图一致性，见上文三步法兜底）。
- **主体保护必须写死**：负面词补 `不要改变食物形态、不要添加或移除道具、不要文字`——
  edit 模型爱顺手"帮忙"换盘子加装饰，和蛋挞"只有一只"是同一类惯性。
- 品牌适配：暗调暖棕 + 压暗背景与黑金调性天然契合，欧包/酥皮/蛋糕类直接用；
  **冰品类（冰面包）不要照抄暖棕**——按三步法色温表换冷调（5600K 日光、低饱和冷背景 + 高饱和主体），
  光效/景深/质感三抓手不变。
- 与写实层冲突提示：本模板的"极致还原 + 电影剧照感"属于**商业提质**，和写实层的"删完美词"方向相反，
  二者别同时上——种草图用写实层，产品提质图用米其林光。

## 高频玩法清单（7 个模板，2026-09-19 从课程截图整理）
"上传一张图 → 得到某类结果"的现成玩法，按用途分四组。括号内是本机的实现路径：

**A 角色与人脸**
1. **面部三十图**：上传人物图 → 得到三视图/多角度，建角色形象库。
   → 用途：《末日觉醒》角色一致性奠基；实现走 `edit`（图生图）。
2. **AI 换脸**：换脸图 + 正面人脸 → 人脸迁移，毛发更细腻。→ `edit` 传两张图。
3. **人脸去 AI 味**：皮肤纹理清晰、质感细腻真实。→ 写实层叠加包（上文六词组）。

**B 风格转换**
4. **九种美术风格指令**：上传无背景图 → 一次出 9 种风格挑喜欢的再深化。
   → 实现：3×3 网格拼图 prompt，或同一主体循环 9 次不同风格段（本技能"整套出图"模板可直接套）。

**C 分镜与视频**
5. **十二宫格分镜**：上传截图 → 12 格分镜，可直接转视频。
6. **二十五宫格分镜**：指令生成完整故事的手绘分镜草图，故事细节更全。
   → 用途：分镜提速；由视频 SOP 驱动，写法见本技能 `prompt_templates.md`。

**D 材质**
7. **超轻材质优化**：上传图 → 服装/材质纹理清晰、质感翻倍。→ `edit` + 材质细节词（羊绒、针织、哑光陶、牛仔纹理）。

> 注意：A/B/D 三组依赖图生图，而本机 `edit` 端点近期上游 503 不稳（见上文"局部修改"坑），
> 失败时就退化成"以原描述重生成 + 材质/风格词加强"。

## 提示词七要素结构（写 prompt 前的必修步骤，2026-09-19 新增）
来源：公众号实操文《为什么 ChatGPT 总画不出你想要的图？8 个实用技巧》。
一句话：**"脑子里有 100% 的画面，却只告诉 AI 20%" 才是出图偏的根本原因**。
写实层管的是**质感**（真不真），七要素管的是**结构**（对不对）。先搭结构，再上质感。

**九要素：用途 + 主体 + 场景 + 风格 + 构图 + 光线 + 细节 + 文字 + 禁止项**

| 要素 | 自问 | 品牌出图常见填法 | 来源 |
|---|---|---|---|
| 用途 | 图放哪？ | 先定用途再定画面——见下方"用途优先级表" | 第三/四篇 |
| 主体 | 第一眼看什么？ | 产品为主，人物为辅，别喧宾夺主 | 第四篇 |
| 场景 | 在哪、正在做什么？ | 用"状态句"而非"属性词"（见写实层） | 第四篇 |
| 风格 | 写实摄影 / 插画 / 杂志 / 3D？ | 抽象词必须翻译成视觉项：留白、配色、元素数量 | 第三篇 |
| 构图 | 主体放哪、哪留白？ | 竖版 1024x1536 / 方版 1:1；主体偏下，上方留标题区 | 第三篇 |
| **光线** | 什么光、从哪来？ | 侧逆光 / 窗边自然光 / 晨光 / 柔和顶光——**去 AI 感的第一杠杆** | 第四篇+写实层 |
| **细节** | 材质、颜色、道具、状态？ | 糖粉、水珠、反光、褶皱、裂口——真实感都藏在这格 | 第四篇+写实层 |
| 文字 | 写什么、放哪、谁大谁小 | **中文一律不在图内写**（见下） | 第三篇 |
| 禁止项 | 绝不要什么？ | 见下"不要清单" | 第三/四篇 |

> 合并说明：第三篇给的是七要素，第四篇是八要素，差别就在**光线**和**细节**被单列出来；
> 加上本地约束"中文不进图"必须单列文字一项 → 定为九要素。
> 补充（2026-09-19 大头贴卡片）：九要素里**构图**这一格当主体是"人"时必须升级——
> 光写"脸居中"必出大头贴，要扩成「镜头/视角 + 构图 + 景别」三件套，详见下方「人物图防大头贴」节。

### 三条执行细则
1. **抽象词必须翻译**：不说"高级/科技感/有质感"，说"大面积留白 + 单一强调色 + 元素不超过三种 + 无霓虹 + 无蓝紫渐变"。
   原文那句：**"不要只告诉 AI 一个形容词，要告诉它这个形容词在视觉上意味着什么。"**
   记忆钩子：**AI 生图不是许愿，是下订单**——你给的格子填得越满，它自由发挥的空间越小。
   **行业术语同理要翻译成视觉描述**（2026-09-19 水电图实测）：
   - 杯梳 → "线管进入底盒处用塑料锁母固定"
   - 弹线 → "墙面上残留淡淡的墨线弹痕"
   - 锡箔纸包交叉 → "强弱电管交叉处包着银色锡箔纸"（模型对"锡箔纸包交叉"执行不稳，需在细节格里重点强调）
2. **"不要"比"要"更有效**：AI 有强惯性套路。烘焙品类的惯性 = 过度暖黄发腻、塑料质感、摆盘过满、
   AI 爱自作主张加乱码招牌字。所以要主动写：
   `画面不要有：CG渲染、3D渲染、塑料质感、任何文字招牌、杂乱摆盘、多余餐具。`
   **负面清单写法（2026-09-19 实测教训）**：不要用"X 以外"的歧义句式（如"盘子以外的多余器皿"
   会被理解成"可以有盘子"），要逐项直列：`不要盘子、不要叉子、不要勺子`。
   数量约束同理：**"画面中只有一只蛋挞"要放在主体句开头加重申**，否则 AI 默认画一堆。
3. **注意这里有一条冲突**：文章建议"图内文字要说清楚主副标题"，
   但**中文写死在图上必乱码**（本技能的已知坑）。所以本流程一律：**图内无字 → PIL 后期叠字**。

### 局部修改，不走重新生成
第一版出来别推倒重来。按"**保留什么 + 只改什么 + 其他不动**"写修改指令，
用 `edit` 动作（图生图）实现：`--images 原图 --prompt "保留主体、构图和风格，只把背景进一步简化、减少装饰元素，其他不变"`
- 一轮只解决一个问题，别一次提五条。
- 想不出画面时，先用 `chat` 动作让模型出 **3 个明显不同的视觉方案**（写明"暂时不要生成图"），
  选定后再生成——比直接"随便做一张"稳定得多。
- **edit 已知坑（2026-09-19）**：默认模型已改为 `agnes-image-2.1-flash`（2.0 上游 500 必挂）；
  edits 队列可能 503 no available server，重试仍挂就用**兜底**：把修改意见合入原 prompt 重新 `image` 生成。
- **竖版 1024x1536 实测可用**（小红书封面 2:3），比 1024x1792 更贴近小红书实际比例。
- **横版 1536x1024 实测可用**（多人场景/家居纪实首选，2026-09-19 验证）。

## 写实增强层（去 AI 感，2026-09-19 新增）
来源：公众号实操文《AI生成图总是一眼假？我换了4句提示词》。核心结论：**AI 感重的根因是"过度完美"**，
把提示词往"日常、带瑕疵、有明暗"方向拽即可。写商务感的图（含大部分烘焙商业图）时，不是每句都用，按下面分层选用。

### 四条硬规则
1. **删完美词**：去掉 `8k / 超高清 / 极致细节 / 完美 / 电影级 / 大师级`。这类词会倒逼模型过度锐化、虚假光滑。
   替换为：`自然画质、原生分辨率、日常拍摄、普通手机拍摄、原相机直出`。
2. **写"状态/痕迹"，不写"属性"**：别写"精致的""好看的"。写"刚出炉还冒热气""面包边角有自然裂口""顾客吃完留下的碎屑"。
3. **给具体参照物，别给模糊风格词**：写"胶片感"不如写"柯达金200胶片"；写"相机直出"要写"索尼A7M3原图直出""iPhone原相机拍摄"。
4. **重塑光影**：AI 默认大平光 = 一眼假。改 `侧光 / 局部光照 / 窗外自然光斜照 / 逆光`，让画面有明暗过渡和体积感。
   再加 `街头抓拍 / 纪实摄影 / 手持拍摄 / 游客随拍 / 非摆拍` 视角词。

### 负面词（本接口无 negative 字段，必须拼进 prompt 尾部）
模板：`画面不要有：CG渲染、3D渲染、塑料质感、基础款、过度磨皮。`
- 本脚本 `tool_agnes.py` **不支持 `--negative`**（接口无该字段），只能 appended 到 prompt 末尾。
- 注意"真实感 ≠ 糊"：写 `轻微自然噪点 / 略带颗粒感 **/ 皮肤纹理自然**` 可以，别写"模糊/马赛克"，会真糊。
- 词不是越多越好：主体 + 状态 + 光 + 画质 四件套写清即可，堆太满模型顾此失彼。

### 人物"活人感"六词组（叠加包，2026-09-19 下午补充）
画**人物**时在原提示词上叠加这 6 组（每组 = 正向 + 负向配对，负向拼尾部）：
| 组 | 正向词 | 负向词 |
|---|---|---|
| 面部 | 可见毛孔、细纹、自然红润、肤色不均 | 不要塑料陶瓷感 |
| 光源 | 明暗变化、头顶光、发丝光、侧光 | 不要均匀受光 |
| 场景 | 光影颗粒、灰尘、噪点、氛围感 | 不要干净无层次 |
| 动作 | 有力量感、走路有力度、衣角随惯性飘动、眨眼自然 | 不要僵硬呆板 |
| 表情 | 微表情、眼神自然聚焦 | 不要空洞无神 |
| 景深 | 前景虚化遮挡、中景人物清晰、背景虚化 | 不要全面平面焦 |
- 景深三层结构（前虚-中实-后虚）对人物图尤其有效，人立刻从"贴在背景上"变成"在环境里"。
- 动作词对"正在进行时"场景（吃饭/刷墙/走路）是关键，能治动作僵硬。

### 场景三段式模板（照抄改主体即可）
- 人像：`一位[状态描述]，头发微乱，衣服有些褶皱，自然微笑，自然画质，日常拍摄，原相机直出，侧光，轻微自然噪点，皮肤有自然纹理。`
- 物品（含产品/静物）：`一个[略带使用痕迹的物件]，有日常使用痕迹和轻微磨损，自然画质，日常拍摄，纪实风格，背景生活化。`
- 场景：`[具体时间+环境，如傍晚街角]，暖黄路灯，行人稀疏，手持抓拍，自然噪点，非摆拍。`

### 落到品牌出图时的边界判断（重要）
- **该用**：顾客场景、街拍/探店氛围图、生活流配图、朋友圈/小红书种草图——文章那套"瑕疵+状态"直接上。
- **慎用**：高端产品线、包装主视觉、门店海报。**商业摄影本就是"精致"，全盘加瑕疵会掉价**。
  这类图只取规则 1（删完美词）和规则 4（侧光），保留质感词，别加"磨损/褶皱"。
- 黑金调性下，把明暗写成"单一侧光源 + 深色背景"反而更贴品牌高级感。

## 人物图防大头贴：把摄影语言写进提示词（镜头 + 构图 + 景别，2026-09-19 整合大头贴卡片）
来源：知识卡片《AI 把人画成大头贴？缺的是摄影语言》（已归档到参考笔记第十节）。
**核心认知：AI 画人的默认失败模式是"大头贴"——只有脸，没有环境、没有构图、没有镜头感。**
这通常是用户的错（提示词里没写够摄影语言），不是模型的错。评论区共识：
**加了光线 + 镜头参数提升明显，本质是把传统摄影的构图知识平移到提示词里。**
解法是像导演/摄影师一样，把**镜头参数 + 构图 + 光线**写进 prompt，让 AI 生成一个"画面"而不是一张"脸"。

### 三个必须写死的维度（人物图专用，治大头贴的核心）
**1. 镜头 / 视角（最关键，直接决定"离人多近"）**
必须写焦距 + 镜头类型，不写 = 默认证件照视角 = 大头贴。
| 想怎么拍 | 写法 |
|---|---|
| 人脸特写但仍带环境 | `85mm 人像镜头，半身构图` |
| 人在环境里（最推荐，最像大片） | `35mm 环境人像镜头，全身入镜，能看到身后房间` |
| 带空间叙事 / 环境压迫感 | `24mm 广角，人物偏一侧，留出环境` |
视角也要写：`平视 / 略微俯拍 / 低角度仰拍`。

**2. 构图（别只写"脸居中"）**
明确：人物在画面里的位置 + 留白给什么 + 谁清晰谁虚。
- `三分法构图，人物位于左三分之一线，右侧留出空间给环境`
- `中心构图，人物居中但半身，背景是虚化的客厅`
与九要素"构图"格联动：竖版封面把人物放下方 2/3 上方留标题；横版纪实把人物放一侧。

**3. 景别 + 景深（与上文六词组的"景深"行组合）**
- 景别：默认给"半身 / 全身"而非"脸部特写"，直接避免大头贴。`半身中景` > `脸部特写`。
- 景深三层（前虚-中实-后虚）：`前景虚化遮挡、中景人物清晰、背景虚化` —— 人立刻从"贴在背景上"变"在环境里"。
- **组合拳**：`35mm 环境镜头 + 三分法构图 + 景深三层` = 一个"在画面里的人"，而不是"贴上去的脸"。

### 人物图标准叠加包（在九要素 + 写实层六词组基础上再补这三项）
```
[镜头] 35mm 环境人像镜头，平视视角，半身中景，人物能看到身后房间一角
[构图] 三分法，人物位于画面左侧三分之一，右侧留白给环境，背景虚化
[景深] 前景虚化遮挡、中景人物清晰、背景虚化
```
再叠加六词组（面部/光源/场景/动作/表情/景深）的质感词，就是一套完整的人物图提示词。

### 反面教材 vs 正面写法（对照，2026-09-19 卡片原例）
| 大头贴（错） | 画面（对） |
|---|---|
| 一个女人微笑 | 35mm 环境人像镜头，平视，一位年轻女性在自家厨房窗边手端咖啡侧身回望，午后斜阳从右侧窗入，三分法构图人物居左，前景料理台虚化、背景窗外绿植虚化 |
| 男人吃蛋挞 | 85mm 半身镜头，一位男士坐在木质餐桌前咬下一口蛋挞，碎屑落在盘中，侧逆光勾轮廓，背景书房书架虚化 |

> 落品牌：人物种草图 / 探店图 / 顾客场景图必须走这套（镜头+构图+景别+六词组全开）；
> 人物海报/高端形象图同理要写镜头与景别，但质感词只取"删完美词 + 侧光"，不必加磨损褶皱。

## AI 海报五步 SOP：参考图反推法（2026-09-19 卡片整合，元流程）
核心观点：**AI 做海报翻车，不是工具不行，是输入太模糊**。把"凭感觉做设计"变成可重复的流水线。
底层公式：**AI 出图 = 文字描述 + 参考图 + 设计要求，三者缺一不可**。
这是一条"元流程"——九要素/三步法/装修 SOP 都是提示词级武器，这条管的是"接到新设计任务时怎么开始"。

| 步 | 动作 | 本机实现 |
|---|---|---|
| 1 理解原理 | 文字+参考图+设计要求缺一不可 | 动手前先检查三样齐没齐，缺参考图就先要 |
| 2 找参考图 | 设计网站挑喜欢的海报，盯**版式/字体/颜色/留白** | 让用户丢截图（如十一海报的云米整装参考图） |
| 3 **反推提示词（最值钱）** | 把参考图丢给 AI 分析构图逻辑/字体特点/配色方式，**别自己从零硬写** | ① 阿鹅直接读图反推（读图能力可用时，最准）；② `chat` 图像理解反推；③ 读图受限时让用户口述参考图要点，按描述反推 |
| 4 生成与调整 | 反推提示词 + 主题 + 文案一起给，不满意**逐条改** | 九要素组 prompt；中文海报走"AI 底图无字 + PIL 叠字"；一轮只改一个维度 |

**已沉淀实例（2026-09-19 十一黄金周装修海报）**：

## 「保真合成」：纯底产品图 100% 保真入场景（2026-09-20 新方法，edit 挂掉时的最佳替代）
**适用**：用户给的是**纯白底/纯色底产品图**，且要求"严格保真、不能和实物有差异"。
**原理**：不重绘产品——**抠出原图像素，贴到 AI 生成的场景空镜上**。产品 100% 是原图，只有背景是 AI 的。

**三步**
1. **生成场景空镜底板**（t2i）：prompt 反复强调`画面中没有任何食物/产品、盘子是空的`，
   避免 AI 自作主张画产品；横竖各出一张，方便两种版式。
2. **本地 PIL 抠图**（纯白底专用，零依赖）：
   ```python
   gray = img.convert("L")
   alpha = gray.point(lambda v: 0 if v >= 245 else (255 if v <= 235 else int((245-v)/10*255)))
   alpha = alpha.filter(ImageFilter.GaussianBlur(1.2))   # 羽化边缘
   cut = img.convert("RGBA"); cut.putalpha(alpha); cut = cut.crop(alpha.getbbox())
   ```
3. **贴图合成**：产品缩放到目标宽度占比 → 居中/偏下定位 → 画椭圆软阴影（`GaussianBlur`）做接地感
   → 叠一层低透明度暖色（如 `(255,186,108,26)`）模拟暖主光 → 输出。
   顺带导出`产品抠图_透明底.png`作可复用素材。

**关键提示**
- 只对**纯底图**有效（先检查四角/四边是否为同一颜色）；实景图/渐变底需换抠图算法（rembg 等）。
- **并发写文件冲突坑**：`ThreadPoolExecutor` 跑 `image` 时若多张落在同一秒，**输出文件名时间戳相同会互相覆盖**（实测已踩）。→ 需要全部保留时必须**串行**出图。
- 与 `edit` 的区别：`edit` 能改产品周围的光影融合（更自然）但依赖上游队列；**保真合成完全不依赖 edit**，是 503 长挂时的确定性方案。

## 出图后的评审环节（可选，借鉴审美类 Skill）
参考同一批资料里的 Impeccable / Taste / Aesthetic 三段式（诊断 → 定风格 → 拆参考），给本流程补一个**出图质检**步骤：
1. **诊断**：出图后用图像理解（`agnes-2.5-flash` 支持图像理解）反问一句
   "这张图最像 AI 生成的地方在哪？列出 3 点并给修改意见"，避开 "文字乱码 / 塑料肤感 / 平光 / 手指异常"。
2. **重绘**：按意见只改一个维度（通常先改光或删完美词），其余锁定，再生成对比图。
3. **归档**：有效改法回填到上文的模板里，形成品牌自己的 prompt 库。

## 本机实测补丁（2026-09-19，写提示词时直接带上）
- **人吃东西**：写实层之外必须补一句「**直接用手拿着吃，不要使用餐具**」，否则模型会自由发挥给主角配筷子/勺子。
- **无文字约束会失效**：只写"无文字"不够，场景类要写成「**绝对不出现任何文字、字母、招牌、logo**」，出图后仍需确认。
- **品牌名会让模型自由发挥动物形象**：画吉祥物时写「**是鹅不是其他动物**」+ 粗短脖 / 橙扁喙 / 橙脚蹼，别只写品牌名加"的吉祥物"。
- **产品/基建类术语要翻译成视觉描述**：如"锡箔纸包交叉"写成"强弱电管交叉处包着银色锡箔纸"，否则模型执行不稳。
