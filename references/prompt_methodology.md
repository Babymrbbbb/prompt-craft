# 提示词组织元方法论（治"AI 假"的底层逻辑）

> 来源：用户 2026-09-19 分享的 3 张"精华提炼"图，与本项目已跑通的"双参考 + 30招物理5规则"互补。
> 核心命题：**AI 视频"假"不是模型问题，是提示词写法问题。** 写提示词不是堆字，而是先理解底层逻辑，再按维度系统化组织——顺序是 **逻辑 → 维度 → 案例**。
> 与 `prompt_templates.md` 的关系：本文件是"怎么组织一条提示词"的元框架；模板文件是可直接套的成品骨架。两者合起来才是完整方法论。

---

## 一、5 大核心维度（提示词的标准骨架）

写任何一条镜头提示词，按这 5 个维度组织，缺一不可。本项目所有模板都落在这 5 格里。

| 维度 | 管什么 | 本项目对应桩点 | 关键写法 |
|---|---|---|---|
| ① 基础定调参数 | 风格 / 画质 / 比例 / 时长 / 基调 | 模板1-4 的画质收尾句 | 先定 film grain / 4K / 比例 / 时长，定调不返工 |
| ② 分镜时序与运镜 | 镜头顺序、动作、推拉摇移、节奏 | 模板1「固定机位」句 + 分镜故事版 | 写清"从哪推到哪"，不写一整段 |
| ③ 光影色调 | 光的方向 / 强度 / 色温、氛围 | 模板2「暖金侧光」、模板6 体积光 | 侧逆光 / god rays / 体积光服务情绪 |
| ④ 音频设计 | 对白 / 音效 / 配乐与画面匹配 | 模板8 配音层 + 过程写法"加声音" | 环境音 / 音效 / 情绪发声指令 |
| ⑤ 基础服化道设定 | 服装 / 化妆 / 道具，角色环境统一 | 资产库 定妆脸 + 场景图 + 素面袋 | 锁脸锁景 + 道具全程统一 |

**用法（自查清单）**：每写完一条提示词，对照这 5 格逐格打勾——缺哪格补哪格。
维度②③④同时也是治"乱穿插 / 不突出"的延伸（写清运镜→不横移乱扫；写清服化道→不串味）。

## 二、情绪驱动写法（治"AI 假"的灵魂）

**核心观点**：真人感靠"情绪"驱动，不是堆画面参数。AI 接不住抽象情绪词（开心 / 难过），必须翻译成可执行的画面 / 发声指令。

### 方法① 情绪前置法则
把情绪放最高优先级**先写**，画面 / 光影 / 运镜全部围绕这个情绪去匹配——**不是反过来先堆参数**。
- ❌ 错误：先写"4K 电影感暖金色调"，再随便塞个"她很开心"
- ✅ 正确：先定"这一镜核心情绪 = 咬下第一口的热烫惊喜"，再选微距 / 慢动作 / 侧逆光去服务它

### 方法② 分层写法（标准化结构）
用固定分层结构强制产出真人情绪质感，**关键是写清"动作的顺序和动态变化"**：
```
[情绪基调] + [动作顺序：起始→变化→落点] + [镜头：从哪到哪] + [光影服务情绪] + [画面参数收尾]
```
（与模板7 物理5规则"给参照点 / 量化"同源：把模糊情绪拆成可执行的顺序步骤。）

### 方法③ 三段式情绪递进（短视频万能公式）
让情绪不是静态一张脸，而是随镜头层层推进、有起伏：

| 段 | 作用 | 写法要点 |
|---|---|---|
| 起 | 铺垫 / 引入 | 平静或日常状态，建立真实感（别一上来就高潮） |
| 承 | 触发 / 发展 | 情绪被某件事点燃（咬下 / 看到 / 听到） |
| 转 | 高潮 / 释放 | 情绪峰值：微表情 + 感官激活全开 |

> 本项目"分镜故事版 6 镜情绪曲线（进店平→挑选聚→品尝高→打包稳→落座缓→定格收）"就是三段式递进的扩展版。

## 三、过程写法 6 招（把提示词当"拍摄执行单"）

**核心观点**：反复抽卡不是 AI 笨，是提示词只给了"结果"、没给"过程"。把它当成一张拍摄执行单来写，AI 才知道怎么一步步拍。

| 招 | 写什么 | 作用 | 示例 |
|---|---|---|---|
| ① 写清过程 | 动作顺序 + 情绪变化 + 镜头落点 | 防动作跳变 | "伸手→捏住→掰开→流心" 不写"掰开蛋挞" |
| ② 明确站位 | 人物 / 物体 / 环境的位置关系 | 防站位乱 | "她站柜台前30cm，蛋挞在左手" |
| ③ 写清镜头 | 从哪推到哪 | 引导注意力 | "从双手特写推到脸" 不写"推近" |
| ④ 加声音 | 环境音 / 音效强化氛围 | 沉浸感 | "酥皮碎裂声、街边白噪" |
| ⑤ 加限制 | "不要 / 避免"排除多余元素 | 防乱入 | "无其他人物、无文字、无畸变" |
| ⑥ 进阶组合 | 角色图 + 场景 + 动作 + 声音 + 限制整套 | 一次到位 | 双参考 + 过程 + 声音 + 限制 |

**进阶组合（招⑥）= 本项目双参考流的标准形态**：
`定妆脸(角色图)` + `场景图` + `动作过程(招①)` + `声音/音频设计(招④)` + `限制句(背景干净无人=招⑤)`，五者同喂。这正是模板1+模板7+模板8 的合体。

## 五、速查：情绪 → 镜头 / 光影 / 发声 搭配表（短视频万能公式）

| 情绪 | 镜头 | 光影 | 发声（配音层） |
|---|---|---|---|
| 惊喜 / 热烫 | 微距推近 + 慢动作 | 侧逆光打亮表面 | 气声 + 尾音上扬 |
| 平静 / 日常 | 固定中景 | 柔顺光 | 平稳叙述 |
| 回味 / 满足 | 脸特写 + 浅景深 | 暖金侧光 | 放慢 + 轻叹 |
| 期待 / 馋 | 产品特写 + 热气 | 体积光 | 吞咽感 / 轻吸 |

> 用法：先在搭配表里定"这一镜的情绪"，再按列取镜头 / 光影 / 发声，最后套进模板1-4 的骨架。（这与「情绪前置法则」一致：情绪先行，参数服务情绪。）
