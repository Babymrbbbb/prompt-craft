# 三大治法提示词模板（直接套）

> 占位符：`{人物}` `{场景}` `{产品}` `{动作}` `{焦段}` `{光线}`
> 每条视频提示词 = 锁脸句 + 锁背景句 + 动作 + 镜头 + 风格 + 画质收尾，按此顺序。

## 1. 人物叙事镜头（双参考：定妆脸 + 场景图）

```
画面主角是参考图中的同一位{人物}，五官、脸型、发型、服装完全保持不变，不出现其他人物；
{动作}；
{场景}，背景干净无人，仅主角一人；
正面中景，固定机位{焦段}，{光线}，电影感胶片颗粒，
画面稳定无畸变无闪烁，无穿模，4K写实，真实皮肤纹理
```

**要点**：
- 锁脸句固定开头，一字不改
- 「背景干净无人，仅主角一人」是治**乱穿插**的核心，每段必写
- 「固定机位」是治**乱穿插**的第二道锁（替代横移/跟随）

## 2. 产品特写镜头（喂产品高光图）

```
微距特写一只刚出炉的{产品}，{产品特征：焦糖面/酥皮层次/蛋液颤动/热气}，
缓慢推近，浅景深背景虚化，暖金色侧光，
产品广告级质感，电影感胶片颗粒，画面稳定无畸变无闪烁，4K高清，细节清晰
```

**要点**：放在整条片子的**前 1-2 镜**，让产品卖点（脆/香/层次）开头就立住，治**产品不突出**。

## 3. 分镜故事版（出九宫格规划叙事）

```
{品牌}TVC广告分镜故事版，{N}行{M}列宫格 storyboard contact sheet，画幅16:9，
白色细边框分隔各画面，同一{人物}+同一{场景}贯穿，
各格剧情依次为：1{镜头1} 2{镜头2} 3{镜头3} ...，
每格电影广告级构图，暖金色调胶片颗粒，不要出现任何文字字幕logo水印
```

## 4. 品牌定格收尾镜头（结尾）

```
画面主角是参考图中的同一位{人物}，对镜头微笑，双手举起{产品}定格，
柔和顺光暖金色调，中心构图，镜头轻微推近后定格，
电影感胶片颗粒，画面稳定无畸变无闪烁，4K写实
```

**要点**：品牌 logo **不写进提示词**（Agnes 会出乱码），袋子写「素面不写字」，logo 用剪映后期贴。

## 通用画质收尾句（每条都加，兜底防翻车）

```
画面稳定无畸变无闪烁，无穿模，人物比例协调，4K写实，真实皮肤纹理/材质细节
```

## 三大翻车速查

| 翻车 | 在提示词里加 |
|---|---|
| 换脸 | 双参考(定妆脸+场景图) + 「同一位…五官脸型发型不变」 |
| 乱穿插 | 「背景干净无人，仅主角一人」+ 「固定机位」 |
| 产品不突出 | 前段插入产品特写镜头 + 结尾品牌定格 |
| **表情过于AI化** | 把情绪标签换成微表情+微动作+微瑕疵（见下方模板5） |
| **产品/主体不生动** | 感官激活：色香味俱全或光影空气感（见下方模板6） |

# 深化方法论（治"过于AI化"和"主体不生动"）

## 5. 活人感表情深化（治 AI 化笑脸）

**核心：不写情绪标签（惊喜/满意/温暖），写"微表情+微动作+微瑕疵"。真人=不完美。**

写法公式：`微表情细节 + 身体物理反应 + 过渡过程 + 一处微瑕疵`

| ❌ AI化（情绪词） | ✅ 活人感（具象细节） |
|---|---|
| 露出惊喜微笑 | 眉毛上扬一瞬又落下、瞳孔放大、嘴角**歪向一侧**（不对称笑） |
| 闭眼享受 | 闭眼，嘴角被温热**下意识抿了一下唇** |
| 轻轻点头 | 头很轻点一下，**喉头有一次吞咽**，眼角挤出细纹 |
| 满足 | 咀嚼时**脸颊鼓起**，**鼻翼微微翕动** |

深化 4 原则：
1. 微动作替代情绪词（"惊喜"→"眉扬+瞳孔放大+歪嘴笑"）
2. 故意留微瑕疵（不对称笑/鼻翼翕动/没忍住的小反应）= 真人与AI的分水岭
3. 加身体物理反应（吃→咀嚼/吞咽/烫到抿唇，不只写脸）
4. 情绪是过渡的（"从平静慢慢变"，非突然出现）

> ⚠️ 微瑕疵是双刃剑：Agnes 高细节微表情可能偶发崩脸。做法——先出"微瑕疵全开版"和"保守版"各一条对比，挑方向再套用到全部镜头。

**深化修正（实测 2026-09-19）：微表情"少而准、要克制"**
- 真人感的关键不是"动作多"，而是"动作少且松弛"。堆满微动作 → AI 全画满 → 脸部抽搐 → 假面。
- 修正做法：单镜头只留 **1-2 个微表情**，幅度一律写「轻微、克制、自然、松弛」；去掉吞咽/鼻翼翕动这类 AI 渲染不出来的细节。
- 最佳做法：先文生图出一张「克制版表情参考图」（松弛自然的脸），再图生视频，比纯 prompt 堆细节稳得多。

## 6. 主体感官激活（治"色香味/光影不足"）

**"色香味俱全"不是产品专属，本质=让画面主体的核心感官特征被充分激活。**

食品主体 = 色 + 香(热气) + 味(暗示口感) + 动态：
- 色：焦糖面/金黄酥皮分层/亮泽，微距+侧逆光打亮表面
- 香：热气袅袅（香的视觉化），**慢动作**让热气更明显
- 味：用动作暗示——掰开露流心、蛋液颤动、酥皮掉屑
- 动态：热气/颤动/掉屑，加 "slow motion"

风景/空间主体 = 光 + 空间纵深 + 空气感 + 动态：
- 光：色温(晨曦/黄昏)+体积光 god rays
- 空间：引导线+前中后景
- 空气：薄雾/飘尘/光斑
- 动态：树叶/水面/云微动

三件套：**微距 + 浅景深 + 慢动作**；"热气/颤动/掉屑/薄雾"是打破 AI 假感的细节弹药。

## 7. 物理真实感 5 规则（来自「AI视频30招」第26-34招，治"假/塌/不自然"）

**① 动作给参照点**（招26/31）：大动作拆"起始姿态→中间→落地姿态"三段，不写连续动作。例：翻跟头不写"翻一个跟头"，写"蹲姿起跳→空中蜷缩旋转360→双脚落地膝盖缓冲站直"。跳跃落地必须写"屈膝缓冲+上半身微前倾+地面灰尘扬起"，脚就不会戳进地里。

**② 接触写三要素**（招33）：接触面 + 压力 + 形变反馈。例："手掌完全贴合桌面、手指平摊、皮肤因按压产生形变"；"手指按下按钮、按钮下陷5mm、指腹有轻微凹陷"。蛋挞掰开版："手指捏住酥皮顶面→向下施压→焦面沿按压线裂开→蛋浆沿裂缝流出"。这是治"物体交互不自然"的核心。

**③ 材质定物理**（招29/30）：先定材质再写褶皱/飘动，加重量感。丝绸=大弧度光滑褶皱，牛仔=硬挺折线褶皱，毛绒=细碎密集褶皱；长发=分层（头顶微动/中幅摆动/发尾惯性延迟），整根一起动就假。

**④ 量化细节**（招27/32）：步幅"70cm"、转身"≤180°"、按钮"下陷5mm"。AI吃具体不吃模糊。

**⑤ 转身分角度+锁脸**（招32）：转身写角度"向右缓慢转90°，头部同步，面部特征全程不变"；>180°拆两镜头不硬转。这是治"转身崩脸"。

# 音频 / 配音层

## 8. 配音层（AI 配音去假三法，治"念稿腔"）

**核心洞察**：AI 配音"假"的根源不在台词，在于缺了 **"怎么说话"** 和 **"为什么这么说"** 两层信息——它收到"这句话"就只念字面，不做演绎。
**重要现实**：Agnes 视频模型 `agnes-video-v2.0` 是**纯视觉生成，不带 TTS**（见 agnes_api.md）。它出的是"画面+口型"，声音要**单独生成配音再对轨**：画面段口型按台词节奏动 → 用剪映自带 TTS / 单独 TTS 生成配音（台词按三法写好）→ 剪映里配音对口型轨。

**三法**（把抽象情绪翻译成可执行发声指令）：

| 技巧 | 抽象→具象翻译 | 台词 / 提示词写法 |
|---|---|---|
| ① 标点控语气 | "一整段" → "有停顿" | 用逗号 / 句号 / 问号 / 省略号切分，让 AI 知道哪停、哪变调，别把台词当一整串读 |
| ② 情绪→发声方式 | "开心 / 难过" → "低声 / 哽咽" | 抽象情绪 AI 接不住，翻译成可执行发声指令（放缓 / 急促 / 带哽咽 / 气声） |
| ③ 真实情境入场 | "一句台词" → "情境 + 身份 + 动机" | 交代场景 / 角色身份 / 说话动机，AI 才懂"为什么这句要这么说" |

**三条规则（焊进本模板）**：
- 台词**带标点**：逗号（气口）/ 句号（落点）/ 省略号（犹豫）/ 问号（上扬）
- 情绪**翻译成发声**：不写"开心"写"尾音上扬+放慢"；不写"难过"写"带哽咽+气声"
- **开场先铺情境**：1 句话交代"谁 + 在哪 + 对谁 + 为什么这句"

**台词写法示范（烘焙门店片"品尝"段）**：

| 层 | ❌ 念稿腔 | ✅ 演绎 |
|---|---|---|
| 情境 | （无） | "她独坐店里，端着刚买的蛋挞，对镜头轻声说" |
| 身份动机 | （无） | "爱烘焙的普通女生，想安利给朋友" |
| 台词 | "这个蛋挞很好吃。" | "真的…很烫，但我忍不住咬了一口（停顿）——焦的那层，脆到不行。" |
| 情绪发声 | （无） | 前半"很烫"气声、后半"脆到不行"放慢、尾音上扬 |

**落地产物（Agnes 流程）**：① 画面段（Agnes 出）人物口型按台词节奏动 → ② 配音用剪映 TTS / 单独 TTS 生成，台词按三法写好 → ③ 剪映配音对口型轨。

> 配音层与"5 维度"的「④ 音频设计」维度、"过程写法 6招"的「④ 加声音」对应——详见 `prompt_methodology.md`。
