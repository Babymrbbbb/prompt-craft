# prompt-craft

**AI 提示词写法库（图像 + 视频）** —— 从"一句话许愿"到"一句话下订单"的实战手册。

本仓库解决一个问题：**这段话到底怎么写。**

---

## 为什么需要这个

AI 生图不是许愿，是下订单。格子填得越满，模型自由发挥的空间越小。

但大多数人的提示词写作停留在"高级感""好看""电影质感"这种抽象词——模型理解不了，只能自由发挥。

本仓库提供：
- **通用铁律**：6 条跨图文通用的写法原则
- **图像篇**：九要素结构、写实增强层、人物防大头贴、美食三步法、米其林光、暗调陷阱、电影感六件、装修 SOP、海报五步、批量同风格、局部修改、出图评审
- **视频篇**：三大治法（双参考锁脸 / 背景无人 / 产品突出）、5 大维度骨架、情绪三法、过程写法 6 招、叙事与"人活过来"方法论
- **元方法论**：组织语言的方式，5 维度 + 情绪驱动 + 过程写法

**所有内容均经过实测验证，不是理论推导。**

---

## 快速开始

### 图像：九要素结构

```
用途 + 主体 + 场景 + 风格 + 构图 + 光线 + 细节 + 文字 + 禁止项
```

主体是"人"时，**构图格**必须升级为「镜头焦距 + 构图 + 景别」三件套，否则必出大头贴。

### 视频：固定骨架

```
锁角色句 → 情绪前置 → 动作过程(起始→变化→落点) → 场景 → 锁背景句 → 固定机位 → 风格收尾
```

### 负面词模板

```
画面不要有：CG渲染、3D渲染、塑料质感、任何文字招牌、杂乱摆盘、多余餐具。
```

---

## 通用铁律（图文通用，动笔前过一遍）

1. **抽象词必须翻译**：不说"高级感"，说"大面积留白 + 单一强调色 + 元素不超过三种"。
2. **"不要"比"要"更有效**：负面清单 append 到 prompt 尾部，逐项直列。
   ❌ "盘子以外的多余器皿" → ✅ "不要盘子、不要叉子、不要勺子"
3. **数量 / 动作写死**：唯一物体放主体句开头（"画面中只有一只…"）；"正在进行时"写"紧贴 / 接触"。
4. **状态 > 属性**：写"刚出炉还冒热气""边角有自然裂口"，不写"精致的""好看的"。
5. **中文永远不进图**：图内无字 + 后期叠字（盒子上写字必乱码）。
6. **一轮只改一个维度**，别一次提五条修改意见。

### 暗调陷阱：只写"暗"不写"主体受光"，模型连主体一起压

做"暗调高级感 / 暗托亮"时，**压暗的对象必须限定为环境与背景**，同时**单独写主体受光**。

| 写法 | 结果 |
|---|---|
| ❌ "深色胡桃木 + 伦勃朗式明暗 + 深褐色虚化" | 主体区亮度 **87.9**，产品发灰不跳 |
| ✅ 加"主光直接落在主体上 / 主体受光充分" + 把压暗限定为"四周环境与背景" | 主体区 **97.7**（+11%），暗托亮成立 |
| ✅ 或干脆走明亮版 | 主体区 **149.1**，产品表现力最强 |

**判断标准（代替目检）**：测主体区（0.55–0.85H）平均亮度 ——
**≥120 才算够亮**，暗调版可放宽到 ≥95，**低于 90 必须回去改 prompt**。

### 电影感（Cinematic）六件

用户要"电影感"时，本质是**要光影叙事，不是要亮**。六件缺一不可：

1. **单一强光源**：只许一盏（高窗侧逆光 / 射灯），写清方向
2. **可见光柱 + 丁达尔**：光束里必须有**悬浮颗粒**（糖粉 / 面粉 / 尘埃）
3. **强明暗对比**：暗部要真暗，别让环境光补亮
4. **窄色域**：焦糖暖调高光 + 深棕阴影，别五颜六色
5. **浅景深 + 柔和光晕 + 胶片颗粒**：三个词一起上
6. **叙事动作**：手在做某件具体的事，不是成品摆拍

**可直接复用的 prompt 骨架**：
```
电影剧照质感的一帧，cinematic food photography[，竖构图]。
画面[下半部/偏右]：<一双戴半透明一次性手套的手 + 正在做的具体动作 + 主体状态>，
<台面材质>，旁边散落<配料>。
[上半部是深褐色虚化背景与大面积暗部区域，]<方向>射入的暖金色侧逆光形成清晰可见的光柱，
空气中飘浮的糖粉颗粒在光束里闪烁，丁达尔效应明显，暗部保留细节。
强烈的明暗对比，焦糖暖调高光与深棕阴影，浅景深，柔和光晕，胶片颗粒质感。
画面中不出现完整人脸，无文字无水印无logo。
```

### 视频篇：三大治法

| 翻车 | 根因 | 治法 |
|---|---|---|
| 换脸 / 身份漂移 | 尾帧无限接力，误差累加 | **双参考**：定妆正脸图（锁脸）+ 场景图（锁景）**同时**喂每镜 |
| 背景乱入路人 | 背景留白 + 横移镜头扫出新空间 | 写死"背景干净无人，仅主角一人" + **固定机位** |
| 产品不突出 | 拍成人物剧情片，产品只是道具 | 前 1–2 镜用产品高光图做微距特写 + 结尾品牌定格 |
| 表情 AI 化 | 写情绪标签而非画面细节 | 微表情 + 微动作 + 微瑕疵（真人=不完美，少而准） |
| 主体不生动 | 只写主体没写感官 | 色香味 / 光影空气感（微距 + 浅景深 + 慢动作） |

### 叙事与"人活过来"方法论

四件事，按重要性排：

1. **提示词污染**（穿帮头号来源）：写"医生"→附赠白大褂听诊器；写"末日废墟"→附赠绿植黄昏。
   **删掉联想词，只写摄像机拍得到的物理动作。做减法反而更好。**
2. **真人行为公式（单人）**：人物身份 + 具体小事 + 下意识小动作 + 情绪落点。
3. **情绪三件套**：情绪前置 + 分层写法 + 三段式递进。
   情绪要写**强度档位**（弱/中/强），别写"很开心"；动作要带**上半身**；要写**时间顺序**。
4. **多人铁律**：一人主动、一人被动反应；**行为动机 > 五官细节**。

**两条硬规则**：词序越靠前权重越高 → 情绪段必须第一；出问题**只改那一句**，整段重写会洗掉已调好的参数。

**生产顺序**：剧本分镜 → 锁角色图 → 锁场景图 → 写提示词 → 逐镜生成 → 后期。
角色图/场景图没做完不许开生成；尾帧接力**最多 3 镜**，超过回退角色图重起。

### 声音

视频模型**不带 TTS**，配音必须单独做。台词按「配音去假三法」写：
**标点控语气**（用标点制造停顿气息）+ **情绪翻译成发声方式**（不是写"开心"，写"声音上扬、尾音带笑、语速略快"）+ **真实情境入场**（第一句像现场开口说话）→ 再丢 TTS 对轨。
